# Идея проекта

Разработать LLM-ассистента в виде Telegram-бота с ролью нутрициолога.

Бот должен отвечать на общие вопросы о питании и оценивать калорийность предоставленного пользователем текстового списка продуктов. Для расчёта пользователь указывает продукты и их количество в граммах, миллилитрах или порциях. Бот оценивает калорийность через LLM без внешней базы продуктов, выводит каждый продукт отдельной строкой и завершает ответ общим итогом в ккал.

Если данных о количестве недостаточно, бот запрашивает уточнение и продолжает расчёт после ответа пользователя. Результат носит оценочный характер, а общие рекомендации по питанию не заменяют медицинскую консультацию.

Бот должен постоянно работать как один облачный сервис в Railway. Изменения ветки `main` автоматически развёртываются из GitHub с использованием существующего `Dockerfile`.
