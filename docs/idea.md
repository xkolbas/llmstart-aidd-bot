# Идея проекта

Разработать полноценный ИИ-продукт в формате Telegram-бота — персонального ИИ-нутрициолога. Его роль, область компетенций, стиль общения и ограничения задаются системным промптом.

Бот помогает пользователю анализировать рацион и принимать повседневные решения о питании. Он учитывает цели пользователя, особенности его питания и контекст диалога. Если для рекомендации не хватает информации о целях, ограничениях, составе блюда или количестве продуктов, бот сначала задаёт уточняющие вопросы и только после этого предлагает решение.

Основные сценарии продукта:

- анализ рациона и рекомендации по его улучшению;
- оценка состава блюда или приёма пищи по фотографии;
- оценка калорийности продуктов и блюд по текстовому описанию или фотографии;
- составление сбалансированного блюда, меню или рациона из продуктов, которые есть у пользователя дома;
- ответы на вопросы о питании с учётом целей пользователя;
- общение не только текстом, но и голосовыми сообщениями для удобного использования в повседневных ситуациях.

Рекомендации должны быть персонализированными, понятными и практичными. Бот объясняет свои выводы, отмечает неопределённость при оценке по фотографии или неполному описанию и не выдаёт предположения за точные данные.

Продукт не заменяет врача: бот не ставит диагнозы и не назначает лечение. При медицински чувствительных вопросах он сообщает о границах своей компетенции и рекомендует обратиться к профильному специалисту.

Бот должен постоянно работать как облачный сервис в Railway. Изменения ветки `main` автоматически развёртываются из GitHub с использованием существующего `Dockerfile`.
